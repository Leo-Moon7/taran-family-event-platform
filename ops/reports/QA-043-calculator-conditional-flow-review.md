## 수정 필요 1 — 표시와 계산 범위 일치

현재 화면의 `5만 원 이하`는 실제로 1인 `3.5만~5만 원`, `12만 원 이상`은
실제로 `12만~18만 원`으로 계산한다. 사용자에게 보이지 않는 하한·상한이 있어
선택한 희망 식대와 결과가 다르게 느껴질 수 있다.

최소 수정:

- `5만 원 이하` → `3.5만~5만 원`
- `12만 원 이상` → `12만~18만 원`
- 설명도 닫힌 계획 범위임을 동일하게 표시
- 전용 테스트에서 네 식대 label과 실제 `range`의 양 끝값 일치를 검사

실제 시세를 새로 정하거나 범위를 늘리는 작업은 하지 않는다.

## 수정 필요 2 — 주 행동 텍스트 대비

계산기 로컬 코랄 `#f4513d` 위 흰색 텍스트 대비는 약 `3.45:1`로, FE-027 카드와
첨부 UI 원칙의 작은 본문 `4.5:1` 기준을 충족하지 않는다. hover 코랄
`#da3c2d` 위 흰색은 약 `4.50:1`이다.

최소 수정:

- 계산기 내부 주 행동 코랄을 흰색 텍스트 대비 `4.5:1` 이상인 색으로 조정
- hover/focus는 기본색보다 명확히 구분되는 더 어두운 색 사용
- 공통 token이나 다른 페이지는 수정하지 않음
- 전용 테스트 또는 보고서에 계산기 로컬 색 대비값을 고정
