  - 호텔·연회장: 식사 중심·연회 진행 포함·숙박 연계
  - 대관 파티룸: 공간만 대관·장식 포함 대관·종일 대관
  - 자택·출장: 직접 준비·출장 케이터링·상차림 중심
  - 야외·가든: 야외 공간 중심·행사·식사 함께·우천 대안 포함
- `state.spaceDetails`에 `cuisine`, `mealBudget`, `useMode`를 저장한다.
- 행사 변경 시 공간·세부 조건·서비스를 초기화하고, 공간 변경 시 이전 공간의 세부 조건과 서비스를 초기화한다.
- 프라이빗 룸은 사용자가 고른 1인 식대 범위를 인원수에 곱한다. 다른 공간은 선택한 이용 방식의 준비 범위를 장소 범위에 더한다.
- 결과 내역에 `식사 · 한정식 · 1인 5만~8만 원`, `장소 · 호텔·연회장 · 연회 진행 포함`처럼 선택 내용을 한국어로 표시한다.
- 5단계 서비스 목록은 행사 기본 항목에 공간별 항목을 더하거나 맞지 않는 항목을 제외한다. 추천 설명도 행사와 공간 조합으로 바뀐다.
- 선택 상태는 색뿐 아니라 `✓ 선택됨`/`○ 선택`과 `aria-pressed`로 전달한다. 필수 세부 그룹은 `fieldset`, `legend`, 도움말 `aria-describedby`를 사용한다.
- 코랄은 주 행동·초점, 녹색은 선택·추천 문맥에 사용하고 계산기 내부에서만 간격·위계·1.5 줄간격·모바일 단일 열 규칙을 추가했다.
- 기존 `TaranSearchContext.toParams/save`, 검색 쿼리 필드, `calculator-state` 저장 키, 업체/체크리스트 링크, 준비 계획용 비시세 안내를 유지했다. 새 세부 조건은 승인 없이 업체 검색 쿼리 계약에 추가하지 않았다.
