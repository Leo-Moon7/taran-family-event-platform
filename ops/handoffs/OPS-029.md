# OPS-029 전달문

`ops/TASK_SPECS.md`의 OPS-029를 최종 명세로 사용한다.

검수 완료된 OPS-024의 `001~014` 설치 문서를 기준으로 migration `015`와
`016`의 순서·역할·중단 조건·적용 후 확인을 추가한다.

다음 계약을 반드시 유지한다.

- 새 프로젝트: `admin-schema.sql` 1회 후 `003`부터 `016`까지 순차 적용
- 기존 프로젝트: `admin-schema.sql` 재실행 금지, 적용 이력과 백업을 확인한
  뒤 누락된 첫 번호부터 순차 적용
- `015`는 `014` 뒤, `016`은 `015` 뒤에만 적용
- `015` 적용 직후 기여·증빙·공개 projection·정확한 금액 runtime은 모두
  `false`
- `015`는 Storage bucket·업로드 URL·signed URL·Storage policy를 만들지 않음
- `016` review queue는 owner·admin·operations와 AAL2만 허용하고 최소 6개
  열·최대 50개만 반환
- 격리 PASS와 문서 병합은 운영 DB·실제 견적·증빙·공개·배포 승인이 아님

migration SQL, 제품 코드, API·DB·환경변수·package/lock은 수정하거나 실행하지
않는다. 범위 밖 문제는 직접 수정하지 않고 총괄 PM에게 보고한다.
